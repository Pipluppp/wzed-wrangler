# wZed Wrangler

[Nodepod](https://github.com/R1ck404/Nodepod)/[wZed](https://github.com/ScelarOrg/wZed) gives an IDE fully in the browser, similar to the closed source products like WebContainers from Stackblitz.

Then recently Cloudflare published
[temporary Workers](https://blog.cloudflare.com/temporary-accounts/) where `wrangler` (their CLI for deploying and managing CF stuff) could now deploy a Worker without any Cloudflare account. 

What if we can use this within the templates created in `wzed` and have temporary deployments? All within a browser.
